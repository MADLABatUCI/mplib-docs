👋 Welcome to the walkthrough tutorial for MPLib.js!

<!--more-->

In this walkthrough tutorial, you will be guided on how to create a **Group Estimation** game. The tutorial will be a comprehensive walkthrough from setting up your firebase database to launching and collecting data for your experiment. The purpose of this walkthrough is to guide you through the various different aspects of creating a multiplayer game using MPLib.js. The aim is that you will be able to create your own new experimental games from scratch given the detailed instructions in this tutorial.
